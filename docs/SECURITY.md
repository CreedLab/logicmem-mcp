# Security

This repository is an unmaintained mirror. The current security policy and vulnerability-reporting process live in the canonical repository:
https://github.com/LogicMem/LogicMem-mcp-/blob/main/docs/SECURITY.md

LogicMem keeps tamper-evident, hash-linked records of AI agent actions and memory operations, so later alteration of a record can be detected on verification. It is designed to support record-keeping duties such as EU AI Act Article 12; it is not a compliance certificate.

Please do not report vulnerabilities in public issues on this mirror; use the process described in the canonical repository.
